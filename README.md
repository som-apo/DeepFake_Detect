# DeepFake Image Detection

An undergraduate project that uses Classical Machine Learning and CNNs to detect deepfake images. The aim is to build a deepfake image detection system using classical ML techniques with performance comparable to CNN models.

## What's inside
- `Classical.ipynb` – classical ML approach to deepfake detection
- `CNN_DeepFake_Detect_Project.ipynb` – CNN-based model for comparison
- `proposal/`, `mid-project-report/`, `final-project-report/` – project proposal and reports
